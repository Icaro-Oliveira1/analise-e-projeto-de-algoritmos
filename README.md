# Análise e Projeto de Algoritmos

Este repositório reúne exercícios, experimentos e anotações desenvolvidos durante a disciplina de **Análise e Projeto de Algoritmos**, do curso de **Ciência da Computação**.

## Proposta

A proposta deste repositório é abordar os conteúdos da disciplina de maneira prática, utilizando a implementação e a experimentação como ferramentas de estudo.

Além de implementar algoritmos, o objetivo é investigar:

- O funcionamento dos algoritmos na prática;
- O comportamento diante de diferentes entradas;
- O impacto do tamanho e das características dos dados;
- A complexidade e o desempenho das soluções;
- Gráficos e visualizações dos resultados;
- As diferenças entre abordagens algorítmicas.

## Organização

Os arquivos são organizados principalmente por aulas e experimentos. Cada script pode conter:

- Implementações de algoritmos;
- Testes com diferentes entradas;
- Análises de desempenho;
- Comparações entre soluções;
- Anotações e observações sobre os resultados.

## Objetivos de estudo

Este repositório tem como objetivos:

1. Desenvolver a capacidade de implementar algoritmos;
2. Compreender o comportamento dos algoritmos experimentalmente;
3. Relacionar a análise teórica com os resultados práticos;
4. Investigar como as entradas influenciam o desempenho;
5. Utilizar gráficos para visualizar e interpretar resultados;
6. Aprimorar o raciocínio para projeto e análise de algoritmos.

## Natureza do repositório

Este é um repositório de estudo e experimentação. Portanto, os códigos podem passar por diferentes versões, conter abordagens alternativas e ser modificados conforme o aprendizado dos conteúdos da disciplina.

Os resultados e implementações aqui presentes representam um processo contínuo de investigação e aprendizado.

## Tecnologias

- Python
- Git e GitHub
- Bibliotecas de apoio para testes, análise e visualização de dados

## Observação

O foco principal deste repositório não é apenas obter uma solução, mas compreender como ela funciona, analisar suas características e investigar seu comportamento em diferentes cenários.
